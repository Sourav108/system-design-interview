# Module 05: Capacity Estimation (Back-of-the-Envelope Math)

The complete mathematical toolkit for estimating scale, storage growth, memory sizing, bandwidth limits, and compute infrastructure in System Design interviews.

---

## 📚 Lessons in this Module

1. [**01: Numbers Every Engineer Should Know**](./01-numbers-every-engineer-should-know.md) — Powers of 2, time constants, latency hierarchy, and hardware throughput ceilings.
2. [**02: Traffic & QPS Estimation**](./02-traffic-and-qps-estimation.md) — Converting DAU to average/peak read and write QPS with worked examples.
3. [**03: Storage Capacity & Growth**](./03-storage-capacity-and-growth.md) — Daily ingestion, 5-year retention math, metadata vs blob sizing, and replication overhead.
4. [**04: Bandwidth & Network Throughput**](./04-bandwidth-and-network-throughput.md) — Ingress vs egress bandwidth math, video bitrate calculation, and CDN offloading.
5. [**05: Memory & Cache Sizing**](./05-memory-and-cache-sizing.md) — The 80-20 Pareto rule, RAM sizing formulas, and Redis cluster topology math.
6. [**06: Server Cluster & Core Estimation**](./06-server-cluster-and-core-estimation.md) — I/O-bound vs CPU-bound instance sizing, Little's Law, and autoscaling headroom.
