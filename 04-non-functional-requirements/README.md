# Module 04: Non-Functional Requirements (NFRs)

Comprehensive architectural guides for quantifying, measuring, and designing the core system invariants of distributed systems.

---

## 📚 Lessons in this Module

1. [**01: Availability**](./01-availability.md) — The math of nines, MTBF/MTTR, SLA/SLO/SLI, and multi-AZ active-active deployments.
2. [**02: Reliability & Fault Tolerance**](./02-reliability-and-fault-tolerance.md) — Reliability vs availability, circuit breakers, jittered backoff, and DLQs.
3. [**03: Scalability**](./03-scalability.md) — Vertical vs horizontal scaling, stateless compute, and the 3-axis Scale Cube.
4. [**04: Performance & Latency**](./04-performance-and-latency.md) — Tail latencies (p99/p99.9) and latency numbers every engineer must know.
5. [**05: Throughput & Bandwidth**](./05-throughput-and-bandwidth.md) — Little's Law ($L = \lambda W$), ingress vs egress bandwidth sizing.
6. [**06: Durability & Data Loss**](./06-durability-and-data-loss.md) — RPO vs RTO, Write-Ahead Logs, synchronous replication, and erasure coding.
7. [**07: Observability**](./07-observability.md) — The 3 pillars (Metrics, Logs, Tracing), the RED method, and OpenTelemetry spans.
8. [**08: Security & Compliance**](./08-security-and-compliance.md) — Zero-Trust architecture, TLS 1.3, mTLS service mesh, and envelope encryption.
